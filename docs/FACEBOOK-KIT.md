# Facebook kit — advertising the contractors on Outback Connections

For Jess and Ali. Every link carries the UTM tag (Josh's rule) so the
traffic shows up in the numbers. Change the region and count to match the
live page before posting. Never post a contractor's phone number; the whole
point is that the listing is the permanent place to find them.

Link pattern (swap the region slug): `?utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_contractors`

- All contractors: https://www.outbackconnections.com.au/services/fencing-contractor?utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_contractors
- Orange: https://www.outbackconnections.com.au/services/fencing-contractor/orange-nsw?utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_contractors
- Dubbo: https://www.outbackconnections.com.au/services/fencing-contractor/dubbo-nsw?utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_contractors
- Wagga Wagga: https://www.outbackconnections.com.au/services/fencing-contractor/wagga-wagga-nsw?utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_contractors
- Post a fencing job: https://www.outbackconnections.com.au/post/service/request?category=fencing-contractor&utm_source=facebook&utm_medium=jess_organic&utm_campaign=fencing_job
- Home: https://www.outbackconnections.com.au/?utm_source=facebook&utm_medium=jess_organic&utm_campaign=home

The region pages come from the "By region" chips on the category page. Only
post a region that has contractors listed.

## Post 4: one contractor at a time (with their say-so)

Only for claimed businesses that have said yes.

> Meet [Business], fencing contractors in [Town]. [One line they gave us
> about what they do.] Ask them for a quote here:
> [Their listing link + UTM]

## What to watch after each post

`/dashboard/admin/analytics` → Traction gate: searches, quote requests,
claims. `/dashboard/admin/demand` → which regions people asked in. If a
post brings searches but no quote requests, the listing page is the problem.
If quote requests but no claims, the invite is the problem.
