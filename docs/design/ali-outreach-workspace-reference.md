# Ali outreach workspace design reference

- Goal: make follow-ups and safe one-at-a-time contractor outreach the primary daily workflow.
- Direction: **Precision Modern** — warm white surfaces, ink text, Outback green accents, amber only for due work, and red only for suppression.
- Reference image: `ali-outreach-workspace-reference.png`
- Scope shown: My work today, one contractor outcome panel, and owner-only team access.
- Product constraints: no bulk sending, no automatic activity logging when an email client opens, no tracking pixels, no invented metrics, and no contact action after suppression.

The reference uses anonymous placeholder data. The implementation should reuse the existing Outback Connections components and styling rather than copy the mockup literally.
